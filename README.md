##  Featured Projects

> Click any project to explore the full repo.

### 👁️ [Eye-Detection Assistive System](https://github.com/MOQA-01)
**1st Place — Kodikon 3.0 National Hackathon**
Real-time gaze-tracking algorithm that enables individuals with limb disabilities to interact with computers using only their eyes. Built with PyTorch + OpenCV, achieving low-latency inference suitable for live use.

`Python` `PyTorch` `OpenCV` `Accessibility` `Real-time CV`

---

### 🎥 [3D CNN Crime Detection](https://github.com/MOQA-01)
Spatiotemporal convolutional network for real-time surveillance video analysis. Detects anomalous activity patterns across frames using a 3D CNN architecture trained on video datasets.

`Python` `PyTorch` `CUDA` `Video Analysis` `Deep Learning`

---

### 🤖 [Humanoid University Assistant Robot](https://github.com/MOQA-01)
End-to-end humanoid robot integrating Computer Vision and NLP for interactive university assistance. Capable of recognising faces, understanding spoken queries, and responding intelligently.

`Python` `ROS` `OpenCV` `NLP` `Robotics`

---

### 💧 [IoT Rural Water Management Platform — ICRTET 2026](https://github.com/MOQA-01)
Published research project: a microservices-based platform monitoring rural water systems via IoT sensors with real-time anomaly detection. Lead researcher and author at ICRTET 2026.

`Python` `IoT` `Microservices` `Anomaly Detection` `Docker`

---

### 🚗 [Kinematic Bicycle Model for AI Racing](https://github.com/MOQA-01)
Physics-based autonomous vehicle model implementing kinematic bicycle dynamics for AI-controlled racing simulations. Includes path planning, steering control, and trajectory optimisation.

`Python` `Simulation` `Autonomous Systems` `Control Theory`
